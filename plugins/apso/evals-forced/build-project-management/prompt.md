Build a complete project and task management system for teams. Create Projects with name, description, owner, start date, target end date, status (planning, active, on-hold, completed), and budget. Add Milestones for key project checkpoints with target dates and completion status. Include Tasks with title, description, assignee, due date, priority (urgent, high, medium, low), status (todo, in-progress, review, done), estimated hours, and actual hours. Build TaskDependencies for blocking relationships between tasks. Create Teams with team name and member assignments. Add TeamMembers linking users to teams with roles (owner, admin, member). Include Comments for task discussions with mentions and reactions. Create Attachments for files linked to tasks or projects. Add TimeEntries for tracking work hours with start/end times, descriptions, and billable flags. Include Labels for categorizing tasks (design, development, testing, documentation). Create Sprints for agile methodology with sprint goals, capacity, and velocity. Finally, add Boards with customizable columns for Kanban-style workflow visualization.

Write the schema to `.apsorc` in the current directory.
