Build a complete online store backend for selling products with full order management. Create a Products entity with name, description, SKU, price, compare-at price, cost, inventory quantity, weight, and multiple product images. Add Categories with hierarchical structure, descriptions, and featured images for navigation. Include ProductVariants for items with options like size, color, or material, each with their own SKU, price, and inventory. Build a Customers table with shipping addresses, billing addresses, order history, and account status. Create a ShoppingCart system with cart items, quantities, and saved-for-later functionality. Add Orders with order number, customer reference, shipping address, billing address, subtotal, tax, shipping cost, discounts, and order status (pending, processing, shipped, delivered, cancelled). Include OrderItems linking products to orders with quantities and prices at time of purchase. Add Coupons with discount types (percentage, fixed amount), minimum order values, usage limits, and expiration dates. Finally, create Reviews for product ratings and customer feedback with moderation status.

Write the schema to `.apsorc` in the current directory.
