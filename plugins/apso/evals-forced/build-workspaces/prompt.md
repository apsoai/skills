Build a complete multi-tenancy and workspace management system for B2B SaaS applications. Create Workspaces as isolated tenant containers with workspace name, slug, owner, plan ID, settings JSON, and status (active, suspended, archived). Add WorkspaceMembers linking users to workspaces with roles (owner, admin, editor, viewer), custom permissions, and invitation tracking. Include WorkspaceInvites with invitee email, role, invite token, expiry, and inviter reference. Build WorkspaceSettings for per-tenant configuration like branding, feature toggles, and integrations. Create WorkspaceDomains for custom domain mapping with domain name, verification status, and SSL settings. Add WorkspaceBilling for per-workspace subscription tracking with plan, payment method, and usage limits. Include WorkspaceAPIKeys for programmatic access with key hash, scopes, last used timestamp, and rate limits. Create WorkspaceWebhooks for integration endpoints with URL, events subscribed, secret, and delivery status. Add WorkspaceAuditLogs for compliance tracking of all workspace activities. Finally, create WorkspaceLimits for enforcing plan-based quotas on users, storage, API calls, and features.

Write the schema to `.apsorc` in the current directory.
