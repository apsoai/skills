Design the data model for a project management app. Users belong to an organization. Organizations have projects; projects have tasks and documents. Users can comment on both tasks and documents, and reply to comments in threads. Users can react to a comment with an emoji, at most once per emoji per user, and the UI shows reaction counts per emoji. Write the result to `.apsorc` in the current directory, then print the final file contents and list anything the schema cannot enforce on its own.
