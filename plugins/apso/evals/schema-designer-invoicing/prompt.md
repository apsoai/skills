Design the data model for a multi-tenant invoicing SaaS. Each organization issues invoices numbered sequentially per organization (INV-1001, INV-1002, ...). Invoices have line items for products. Product prices change over time: we need to know which price applied on any given date, and an old invoice must keep the prices it was issued with. A customer can be an individual or a company. Write the result to `.apsorc` in the current directory, then print the final file contents and list anything the schema cannot enforce on its own.
